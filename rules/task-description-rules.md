# Which rules to use

- **New tasks (in-house):** `inhouse-rules-v1.md` in this folder. The master copy is the Rules screen of the Verlet Task Agent app.
- **Old workbook (verlet-real-tasks):** its own `docs/02_RULES_AND_WORDS.md` and `docs/10_RULES_SHEET.md`.
- **Customer tasks:** each customer gets its own rule group, added beside the in-house one when the first customer job arrives.

The older copy of the fixed-zone rules that used to be here was removed on 10 Nov 2026 so the two rule sets cannot be mixed up.
